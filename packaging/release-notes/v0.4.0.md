Put a picture behind you in any video app on Linux: Discord, Slack, Zoom, Teams, Meet, OBS. Webcam Blur adds a virtual camera for each webcam, so the app needs no background feature of its own.

![Sally Ride in front of the ISS cupola](https://raw.githubusercontent.com/asloth/webcam-blur/v0.4.0/docs/images/background-cupola.jpg)

## New

- **Background image.** Tray menu → *Background* → *Choose image…*. Any size works: the picture is scaled and centre-cropped to fill the frame, never stretched.
- **Recent images.** The last 5 images stay in the *Background* menu, one click to switch. *Clear recent* empties the list.
- **Live switching.** Changing the image during a call takes effect within a frame or two. The new image loads in the background, so the video does not stall.
- **Safe fallback.** If the image is deleted, moved or can't be read, you get the blur, and the image is tried again every 2 seconds. The menu marks it as *Image not found*.
- **Spanish** translation.

## Install (Arch Linux)

Add this to `/etc/pacman.conf`:

```
[asloth]
SigLevel = Optional TrustAll
Server = https://github.com/asloth/webcam-blur/releases/download/repo
```

```sh
sudo pacman -Sy webcam-virtual-background
```

If pacman asks which `python-onnxruntime` to install, pick `python-onnxruntime-cpu`. It replaces the AUR `webcam-blur` (0.3.0, no background images) and keeps your settings. To build it yourself, download `PKGBUILD` and `webcam-virtual-background.install` below and run `makepkg -si`.

Other distributions: see [Installation](https://github.com/asloth/webcam-blur#installation).
